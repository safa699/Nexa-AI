## ✨ Features

- 💜 Modern and user-friendly UI
- 🚀 Custom splash screen and app logo
- 🔐 Email and password login interface
- 📝 User sign-up screen
- 🌐 Google Sign-In button interface
- 🏠 Home screen navigation
- 📱 Android application built with Java and XML

## 🛠️ Tech Stack

- **Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Build System:** Gradle (Groovy)
